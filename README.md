SOLMARINA is a complete top-down 2D open-world crime game in plain Canvas 2D — a procedural coastal city with driving and car theft, traffic and pedestrians, a 1–5 star wanted system with police chases, five story missions, on-foot combat, a canvas minimap HUD, WebAudio synth sound and localStorage saves. All hand-written, zero network requests at runtime.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
